# CS2-GODOT — упрощённый Counter-Strike 2 на Godot 4 (GDScript)

Полностью **процедурная** 3D-игра: карта, небо, освещение, игрок, боты и HUD
создаются скриптами в рантайме. Никаких внешних ассетов (.glb/.png/.ttf/.wav)
и никакой ручной сборки дерева сцен — в редакторе нужна ровно одна сцена
`Main.tscn` (корневой `Node3D` + скрипт `main.gd`), и она уже лежит в репозитории.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Main.tscn` | Единственная сцена: `Node3D` + `main.gd` |
| `main.gd` | Корень: Input Map в коде, небо/солнце, карта Dust 2, спавн игрока и ботов, раунды |
| `player.gd` | FPS-контроллер: WASD, прыжок, приседание (lerp коллизии и камеры), обзор мышью, HP |
| `weapon_manager.gd` | 3 слота: AK-47 (авто), Glock-18 (полуавто), нож; хитскан, отдача, трассеры, перезарядка |
| `bot.gd` | ИИ: патруль, проверка видимости через `PhysicsRayQueryParameters3D`, погоня, стрельба очередями, смерть с падением |
| `hud.gd` | Весь интерфейс кодом: прицел, HP, патроны, K/D, килл-фид, экран победы/поражения |
| `fx.gd` | Утилиты эффектов: трассеры, вспышки, следы попаданий |

## Быстрый старт (Godot 4.8-dev1)

1. Скачайте и распакуйте Godot 4.8-dev1 (Windows: `Godot_v4.8-dev1_win64.exe.zip`).
2. Откройте Godot → **Import** → выберите папку этого проекта (файл `project.godot`).
3. Нажмите **F5** (Run Project) — игра запустится сразу.

### Если создаёте проект с нуля вручную

1. **New Project** → пустой проект (renderer — Compatibility или Forward+).
2. **Scene → New Scene** → корневой узел `Node3D`, переименуйте в `Main`.
3. Выберите узел → кнопка **Attach Script** (иконка свитка) → путь `res://main.gd`
   (сначала скопируйте все `.gd` файлы в папку проекта).
4. Сохраните сцену как `Main.tscn` (Ctrl+S).
5. **Project → Project Settings → Application → Run → Main Scene** → `Main.tscn`.
6. Больше в редакторе делать ничего не нужно: игрок, боты, карта и HUD создаются кодом.

## Управление (раскладка не важна — физические коды клавиш)

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение |
| `Space` | Прыжок (на ящики 1 м — запрыгиваются) |
| `Ctrl` | Приседание (плавное, с проверкой потолка) |
| Мышь | Обзор (курсор захвачен; `Esc` — освободить, клик — вернуть) |
| `ЛКМ` | Стрельба / удар ножом |
| `R` | Перезарядка |
| `1` / `2` / `3` | AK-47 / Glock-18 / Нож |
| `Enter` | Рестарт раунда после его окончания |

## Геймплей

- 5 ботов патрулируют арену; заметив вас (конус зрения + рейкаст прямой видимости),
  они преследуют, стрейфят и стреляют очередями с задержкой реакции и разбросом.
- Выстрелы слышны ботам в радиусе ~26 м — они приходят проверять источник звука.
- Хедшот (попадание выше 1.45 м от ног бота) наносит множитель урона; AK-47 с
  хедшотом убивает с одного выстрела, как в CS.
- Победа — все боты устранены; поражение — вы погибли. Счёт Kills/Deaths
  сохраняется между раундами; `Enter` мгновенно запускает новый раунд.

## Настройка баланса

- Скорости/прыжок/приседание — константы в начале `player.gd`.
- Урон, магазин, темп стрельбы, разброс, отдача — словари в `weapon_manager.gd`
  (`_define_weapons()`).
- Зрение/реакция/урон/скорость ботов — константы в начале `bot.gd`.
- Число ботов и точки спавна — `BOT_COUNT` и `BOT_SPAWNS` в `main.gd`.

## Экспорт в .exe для Windows (Godot 4.8-dev1)

1. **Project → Export → Add… → Windows Desktop** — создаётся пресет.
2. Нужны export-шаблоны. Стандартная кнопка **Manage Export Templates → Download
   and Install** ищет шаблоны на официальном зеркале, где лежат только стабильные
   версии — для `4.8-dev1` она, скорее всего, ничего не найдёт. Два рабочих пути:

   **Вариант А (рекомендуется) — шаблоны со страницы релиза:**
   - Откройте https://github.com/godotengine/godot/releases/tag/4.8-dev1
     (или https://github.com/godotengine/godot-builds — там тоже лежат сборки dev-версий).
   - Скачайте `Godot_v4.8-dev1_export_templates.tpz`.
   - В редакторе: **Editor → Manage Export Templates… → Install from File** →
     выберите скачанный `.tpz`. Шаблоны распакуются в
     `%APPDATA%\Godot\export_templates\4.8.dev1\`.

   **Вариант Б — указать шаблон вручную:**
   - `.tpz` — это обычный zip. Распакуйте его: внутри папка `templates/` с файлами
     `windows_release_x86_64.exe` и `windows_debug_x86_64.exe`.
   - В пресете экспорта раскройте **Debug → Custom Template** и укажите путь к
     `windows_debug_x86_64.exe`, в **Release → Custom Template** — путь к
     `windows_release_x86_64.exe`.
   - Либо соберите шаблон сами из исходников Godot: `scons platform=windows target=template_release`.

3. Нажмите **Export Project** (не «Export All» с одним пеком) → выберите папку →
   получите `имя.exe` + `имя.pck` (рядом должен лежать .pck).
4. Если шаблоны так и не нашлись — временный обходной путь: положите рядом
   `Godot_v4.8-dev1_win64.exe` и ваш `.pck` и запускайте:
   `Godot_v4.8-dev1_win64.exe --main-pack CS2Godot.pck`
   (dev-редактор умеет работать как рантайм для паков).
