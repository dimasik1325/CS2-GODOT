# CS2-GODOT v2.0 — упрощённый Counter-Strike 2 на Godot 4 (GDScript)

Полностью **процедурная** 3D-игра: главное меню, карты, модели, звуки, кейсы и
HUD создаются скриптами в рантайме. Никаких внешних ассетов (.glb/.png/.ttf/.wav)
— ни одного. В редакторе нужна ровно одна сцена `Main.tscn` (корневой `Node3D`
+ `main.gd`), и она уже лежит в репозитории.

## Что нового в v2.0

- **Главное меню**: PLAY, выбор карты, сложность (Easy/Normal/Hard), число ботов,
  длина матча — всё на фоне живой 3D-карты с облётом камерой.
- **Настройки** (сохраняются в `user://settings.cfg`): тени, качество теней,
  MSAA, масштаб разрешения, FOV, яркость, туман, полный экран, V-Sync,
  громкость, чувствительность мыши, FPS-счётчик, радар.
- **Кейсы и скины**: деньги за убийства и раунды ($300/$750 нож/$1000 за раунд),
  кейс за $500 с анимацией прокрутки, 5 уровней редкости (Mil-Spec → Gold),
  21 скин для AK-47 / Glock-18 / ножа, инвентарь с экипировкой.
  Сохранение в `user://save.cfg`.
- **4 карты × 3 планировки**: Dust, Winter, Industry, Sunset — каждая со своим
  небом, солнцем, туманом и палитрой; планировки Arena / Crossroads / Compound
  (форт с воротами, внутрь можно зайти).
- **«Нормальные модельки»**: у ботов — ноги с анимацией шага, руки наводятся на
  игрока по вертикали, шлем, разгрузка с подсумками; у оружия — детализированные
  примитивы (мушка, целики, насечки затвора, изогнутый магазин из 3 сегментов,
  дульный тормоз); ящики с крышками и планками, контейнеры с рёбрами, бочки с
  обручами, мешки с песком.
- **HE-гранаты** (G или 4): физический снаряд с запалом, мигает, взрыв с уроном
  по радиусу (проверка стен), самоурон, тряска камеры, взрыв ослепляет ботов
  (реагируют на звук).
- **Процедурный звук**: все звуки синтезируются в коде — выстрелы AK/пистолета,
  щелчок пустого магазина, перезарядка, нож, попадания/хедшоты/килл, взрыв,
  шаги, приземление, урон, победа/поражение раунда, интерфейс и кейсы.
  Позиционные 3D-звуки для выстрелов ботов и взрывов.
- **Реалистичнее**: прицеливание ПКМ (сужение FOV и разброса), паттерн отдачи
  AK-47 (вверх, затем вправо-влево), свэй и покачивание оружия, выброс гильз
  с физикой, пыль при приземлении, шаги, тряска камеры при уроне.
- **Радар** (вращается с игроком, точки ботов), счёт матча «YOU x : y BOTS»,
  фриз-тайм с обратным отсчётом, килл-фид, хитмаркеры.
- **Пауза** (Esc): продолжить / настройки / выйти в меню.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Main.tscn` | Единственная сцена: `Node3D` + `main.gd` |
| `main.gd` | Корень: Input Map в коде, меню↔матч, фриз-тайм, раунды/матч, деньги, карта |
| `menu.gd` | Главное меню, настройки, кейсы (анимация открытия), инвентарь, пауза |
| `map_builder.gd` | 4 темы × 3 планировки, все пропсы со коллизиями |
| `player.gd` | FPS-контроллер: движение, присед, прицеливание, шаги, тряска |
| `weapon_manager.gd` | AK-47 / Glock-18 / нож + гранаты, отдача-паттерн, свэй, скины |
| `bot.gd` | ИИ: патруль/поиск/бой, рейкасты, очередь с задержкой реакции, анимации |
| `hud.gd` | Весь игровой интерфейс + радар (внутренний класс с `_draw`) |
| `menu.gd` | UI меню/настроек/кейсов/инвентаря |
| `settings_manager.gd` | Настройки: хранение и применение (графика/звук/окно) |
| `save_manager.gd` | Экономика и инвентарь: `user://save.cfg` |
| `skins.gd` | Каталог скинов, редкости, взвешенный рандом кейса |
| `sfx.gd` | Синтез всех звуков (AudioStreamWAV из кода) |
| `grenade.gd` | Физическая граната с запалом и взрывом |
| `fx.gd` | Трассеры, вспышки, взрывы, гильзы, пыль |

## Быстрый старт (Godot 4.8-dev1)

1. Скачайте Godot 4.8-dev1, откройте → **Import** → папка проекта (файл `project.godot`).
2. **F5** — откроется главное меню на фоне карты. Нажмите PLAY.

## Управление (раскладка не важна — физические коды клавиш)

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение |
| `Space` / `Ctrl` | Прыжок / приседание |
| Мышь | Обзор; `ЛКМ` — огонь; `ПКМ` — прицеливание |
| `R` | Перезарядка |
| `1` / `2` / `3` | AK-47 / Glock-18 / нож |
| `G` или `4` | Бросить HE-гранату |
| `Esc` | Пауза (в меню — назад) |
| `Enter` | Следующий раунд / возврат в меню после матча |

## Экономика и кейсы

- Убийство: **$300** (нож — **$750**), раунд: **$1000** за победу / **$400** за поражение,
  победа в матче: **+$1000**. Кейс: **$500**.
- Шанс редкости: Mil-Spec 45%, Restricted 30%, Classified 17%, Covert 7.5%,
  Gold (нож) 0.5%. Выпавший скин экипируется автоматически, сменить — в инвентаре.

## Настройка баланса

- Константы в начале `player.gd`, `weapon_manager.gd`, `bot.gd`, `grenade.gd`.
- Пресеты сложности ботов — `Bot.DIFFICULTIES`.
- Скины — `Skins.CATALOG` в `skins.gd`.
- Награды — константы `main.gd`.
- Темы/планировки — `MapBuilder.THEMES` / методы `_layout_*`.

## Экспорт в .exe для Windows (Godot 4.8-dev1)

1. **Project → Export → Add… → Windows Desktop**.
2. Стандартный «Download and Install» шаблоны не найдёт (зеркало хранит только
   стабильные версии). Два пути:
   - **А:** скачайте `Godot_v4.8-dev1_export_templates.tpz` со страницы релиза
     `github.com/godotengine/godot/releases/tag/4.8-dev1` (или `godot-builds`) →
     **Editor → Manage Export Templates… → Install from File**.
   - **Б:** распакуйте `.tpz` (это zip) и в пресете укажите **Custom Template**:
     `windows_release_x86_64.exe` для Release, `windows_debug_x86_64.exe` для Debug.
3. **Export Project** → получите `.exe` + `.pck`.
4. Запасной вариант: `Godot_v4.8-dev1_win64.exe --main-pack игра.pck`.
